# 🧩 Frontend Architecture (Current Learning)

I currently follow a scalable **4 Layer Frontend Architecture** pattern while building React applications.

```text
UI Layer
   ↓
Hook Layer
   ↓
State Layer
   ↓
API Layer
```

---

# 🎨 UI Layer

Responsible for:

- Rendering UI
- Navigation
- User Interaction
- Feed Rendering
- Form Handling

---

# 🪝 Hook Layer

Responsible for:

- Authentication Logic
- Feed Fetching Logic
- Business Logic
- Connecting UI & APIs
- Async Operations
- Like / Unlike Logic

---

# 🧠 State Layer

Responsible for:

- Global State
- User State
- Feed State
- Loading State
- Shared Application State
- Persistent Authentication State

---

# 🌐 API Layer

Responsible for:

- Backend Communication
- Axios Requests
- API Handling
- Request Configuration
- Cookie-Based Requests
- Cross-Origin Requests

---

# 🔄 Authentication Flow (Current Learning)

```text
User Login/Register
        ↓
Frontend Sends Request
        ↓
Backend Validates User
        ↓
JWT Token Generated
        ↓
Token Stored in Secure Cookie
        ↓
Frontend Automatically Sends Cookie
        ↓
Protected Routes Verify JWT
        ↓
Redis Blacklist Validation
        ↓
Authenticated User Access Granted
```

# 🧪 Practice & Exploration Projects

## 😀 AI Face Expression Detection

### 🌐 Live Deployment

- Live Demo: https://face-expression-detect.vercel.app

A small practice project built to explore how developers work with technologies they are learning for the first time.

This project was created after learning about real-world developer workflows, where developers often explore unfamiliar technologies using documentation, experimentation, web research, debugging, and AI-assisted learning.

The project uses Google's MediaPipe Face Landmarker to detect facial expressions in real time through webcam input.

### Features

- Real-time webcam face detection
- Expression Detection:
  - Happy 😀
  - Surprised 😲
  - Neutral 😐
- Face landmark tracking using MediaPipe
- Browser-based AI processing

### Tech Used

- React
- Vite
- MediaPipe Tasks Vision
- Webcam API

### What I Learned

- Integrating AI/computer vision libraries into React
- Working with webcam streams in browser
