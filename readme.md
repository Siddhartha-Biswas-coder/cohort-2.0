# 🧩 Frontend Architecture (Current Learning)

I currently follow a scalable **4 Layer Frontend Architecture** pattern while building React applications.

```text
UI Layer
   ↓
Hook Layer
   ↓
State Layer
   ↓
API Layer
```

---

# 🎨 UI Layer

Responsible for:

- Rendering UI
- Navigation
- User Interaction
- Feed Rendering
- Form Handling

---

# 🪝 Hook Layer

Responsible for:

- Authentication Logic
- Feed Fetching Logic
- Business Logic
- Connecting UI & APIs
- Async Operations

---

# 🧠 State Layer

Responsible for:

- Global State
- User State
- Feed State
- Loading State
- Shared Application State
- Persistent Authentication State

---

# 🌐 API Layer

Responsible for:

- Backend Communication
- Axios Requests
- API Handling
- Request Configuration
- Cookie-Based Requests

---

# 🔄 Authentication Flow (Current Learning)

```text
User Login/Register
        ↓
Frontend Sends Request
        ↓
Backend Validates User
        ↓
JWT Token Generated
        ↓
Token Stored in Cookie
        ↓
Frontend Automatically Sends Cookie
        ↓
Protected Routes Verify JWT
        ↓
Authenticated User Access Granted
```
