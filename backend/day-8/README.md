# Full Stack Project

A full-stack web application built using React, Node.js, Express, and MongoDB.

## 🚀 Live Demo

🔗 Deployed Link: https://cohort-2-0-8hp8.onrender.com/

## 🛠 Tech Stack

### Frontend
- React
- Axios

### Backend
- Node.js
- Express.js
- MongoDB

## ✨ Features
- User authentication
- CRUD operations
- Responsive UI
- API integration

## 📂 Project Structure

```bash
day-8/
│
├── frontend/   # React frontend
├── backend/    # Node.js + Express backend
```

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Siddhartha-Biswas-coder/cohort-2.0.git
```

### Run Frontend

```bash
cd frontend
npm install
npm run dev
```

### Run Backend

```bash
cd backend
npm install
npm start
```
