# 🚀 macOS Portfolio Clone

A sleek and interactive **macOS-inspired portfolio website** built with **React, Vite, and SCSS** — designed to feel like a real desktop experience.

This project features draggable windows, a fully interactive terminal, Spotify integration, GitHub dashboard, notes app, and a modern aesthetic inspired by macOS.

---

# ✨ Features

- 🖥️ macOS Desktop Inspired UI
- 🪟 Draggable & Resizable Windows
- 💻 Interactive Terminal CLI
- 🎵 Spotify Integration
- 📄 Resume Viewer
- 📝 Notes Application
- 🐙 GitHub Integration
- 🎨 Custom SCSS Styling
- ⚡ Fast Performance with Vite

# ⚙️ Installation

## 1️⃣ Clone the repository

```bash
git clone https://github.com/Siddhartha-Biswas-coder/cohort-2.0/tree/main/projects/react-project.git
```

## 2️⃣ Move into the project directory

```bash
cd react-project
```

## 3️⃣ Install dependencies

```bash
npm install
```

## 4️⃣ Start the development server

```bash
npm run dev
```

# 🪟 Main Components

## 🔹 MacWindow.jsx
Reusable draggable macOS-style window component built with `react-rnd`.

## 🔹 Cli.jsx
Interactive developer terminal built using `react-terminal-ui`.

## 🔹 Spotify.jsx
Embedded Spotify playlist player inside a draggable window.

## 🔹 Github.jsx
Displays GitHub-related information using local JSON assets.

## 🔹 Resume.jsx
Embedded PDF resume viewer.

## 🔹 Note.jsx
Minimal notes application inspired by macOS Notes.
